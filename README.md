# Чат-бот для сайту адвоката zoriana.biz

Прототип гібридного чат-бота: кнопки й правила за деревом рішень (17 станів, 5 кінцевих), ML-класифікатор вільного тексту, передача звернення адвокату. Лабораторна робота № 4 з дисципліни "Управління життєвим циклом інтелектуальних систем" (НТУ "ХПІ", 2026).

*A hybrid rule-based + ML chatbot prototype for a lawyer's website: a dialogue controller implementing a 17-state decision tree, a TF-IDF + logistic regression intent classifier with confidence zones, human handoff, and scenario tests that check decision-tree edge coverage.*

## Як це працює

```
вебчат (static/index.html)
   │  POST /api/event
   ▼
controller.py ── кнопки → правила (С1–С12, С15–С17)
   │  вільний текст поза полями імені й телефону
   ▼
nlu/ (С13) ── намір, напрям, фрагмент сайту, впевненість
   │  висока → гілка за наміром; середня → перепитати (С14); низька → уточнення (С15), вдруге → адвокат
   ▼
Inbox ── звернення адвокату (data/handoffs.jsonl, сторінка /inbox) і журнал нерозпізнаних фраз
```

- Бот не складає власних відповідей: усе, що він каже про послуги, – тексти сайту (`content.py`).
- Класифікатор лише обирає гілку: контролер сам вирішує, куди перейти, тому модель можна замінити (наприклад, на LLM із жорстким переліком відповідей), не змінюючи правил. Спільний інтерфейс – `nlu.Classifier` і `nlu.NluResult`.
- Передача адвокату – імітація: звернення з ім'ям, телефоном, напрямом, позначкою терміновості і текстом питання зберігаються на сервері і видні на сторінці `/inbox`.

## Запуск

```bash
uv venv --python 3.12 .venv            # або python3.12 -m venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/uvicorn zoriana_bot.web:app --port 8000
```

Чат: http://127.0.0.1:8000 (з `?demo` – коди станів, переходи і результат класифікатора), скринька адвоката: http://127.0.0.1:8000/inbox. Пауза до нагадування задається `IDLE_SECONDS` (типово 600). Модель навчається автоматично під час першого запуску (`nlu/model.joblib`).

## Тести й артефакти

```bash
uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python -m pytest -q             # 54 тести: сценарії, правила контролера, класифікатор, HTTP API
.venv/bin/python scripts/run_cases.py     # 29 тест-кейсів → artifacts/test_results.json, coverage.json
.venv/bin/python scripts/evaluate_nlu.py  # крос-валідація класифікатора → artifacts/nlu_metrics.json
.venv/bin/python scripts/screenshots.py   # діалоги в Chrome (Playwright) → artifacts/screenshots/
```

Тест-кейси (`zoriana_bot/cases.py`) відтворюють сценарії S1–S8 лабораторної роботи № 2 і проблемні ситуації. Частина проходить через справжній класифікатор, частина – через заглушку (`nlu/stub.py`), яка дає детерміновані результати і запам'ятовує виклики, щоб перевірити, що саме контролер передав класифікатору. `test_edge_coverage` вимагає, щоб кейси пройшли всі 55 ребер дерева рішень. Виявлені помилки та виправлення – `artifacts/fixes.md`.

## Структура

| Файл | Призначення |
|---|---|
| `zoriana_bot/content.py` | тексти сайту: напрями, часті питання, ціни, телефон |
| `zoriana_bot/tree.py` | стани, кінцеві стани і ребра дерева рішень |
| `zoriana_bot/controller.py` | контролер діалогу, сесія, імітація передачі адвокату |
| `zoriana_bot/nlu/dataset.txt` | 373 навчальні фрази українською й російською |
| `zoriana_bot/nlu/model.py` | TF-IDF (символьні 2–5 + слова 1–2) + логістична регресія, зони впевненості |
| `zoriana_bot/nlu/stub.py` | заглушки для тестів: наперед задані результати, недоступний сервіс |
| `zoriana_bot/web.py`, `static/` | FastAPI, вебчат, сторінка `/inbox` |
| `zoriana_bot/cases.py` | тест-кейси як дані |

## Обмеження прототипу

- Точність класифікатора виміряна на фразах, складених розробником (крос-валідація 0,745). У зоні високої впевненості він правий у 88 % випадків, у середній – лише в 37 %, тому там бот перепитує.
- Справжнього підключення адвоката немає (імітація через `/inbox`); сесії зберігаються в пам'яті й зникають після перезапуску.
- Ключів API прототип не використовує; дані звернень (`data/`) і модель (`model.joblib`) у репозиторій не потрапляють.
